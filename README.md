🎮 Mini Games Collection

Welcome to my Mini Games Collection! This repository contains a collection of fun, console-based games built to explore programming, improve logical thinking, and practice problem-solving skills.

Currently, the collection includes three games, with more coming soon! :)

🕹️ Games Included

1. ✊ Rock Paper Scissors

A classic game where you play against the computer by choosing rock, paper, or scissors.

Rules:

Rock beats scissors.

Scissors beats paper.

Paper beats rock.

If both choose the same option, it's a tie.

Features:

Play against the computer.

Random computer choices.

Automatic winner determination.

2. 🎲 Dice Game

A two-player dice game where players choose how many dice to roll, up to a maximum of six. Each player's dice are rolled, and their total scores are compared to determine the winner.

Rules:

Two players compete against each other.

Each player chooses how many dice to roll, up to six.

Each die generates a random result.

The player with the higher total score wins.

If both players have the same total, the player who rolled fewer dice wins.

Features:

Two-player gameplay.

Customizable number of dice rolls.

Random dice results.

Automatic score calculation and winner determination.

3. 🔢 Number Guessing Game

A guessing game where you try to guess a secret number between 1 and 100 generated by the computer.

Rules:

The computer randomly selects a number between 1 and 100.

Enter your guess and follow the hints.

If your guess is too high, the game tells you.

If your guess is too low, the game tells you.

Keep guessing until you find the correct number!

Features:

Random number generation.

Helpful high-or-low hints.

Tracks the number of valid guesses.

Input validation for guesses outside the allowed range.
